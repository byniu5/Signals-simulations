Radio beam steering with a 4-element array

Four antennas transmit the same signal. Shift the phase of each one and the waves reinforce each other in a different direction – the beam is steered without moving anything.

How it works

Every element is a point source sending out a circular wave. At any point of the plane the total field is the sum of the four waves, each with its own travel distance rₙ and its own phase offset φₙ:

E(x, y, t) = Σₙ aₙ · cos(ωt − 2π·rₙ/λ + φₙ)

Far away, the distances differ by yₙ·sin θ, so the waves add in phase in the direction where the geometric delay is cancelled by the electrical phase shift:

φₙ = −2π · (yₙ / λ) · sin θ₀ → Δφ = 2π · (d / λ) · sin θ₀ between neighbours

The polar plot is exactly this sum evaluated at infinity (the “array factor”). The coloured picture is the same sum evaluated everywhere – so you can see the beam forming out of the interference of four circular waves.

Things to try

  1. Put the array in Broadside (all phases 0°) – the beam goes straight ahead. Watch the wavefronts: they are parallel to the array.
  2. Drag the steering angle. The four phases follow a linear ramp and the wavefront tilts together with the beam.
  3. Now go manual: set the phases to 0°, 45°, 90°, 135° (top to bottom) and check the main-beam readout against the formula above.
  4. Switch to Intensity to see the static lobe structure, then compare it with the polar plot.
  5. Increase the spacing beyond 0.5 λ – extra grating lobes appear. At d = 1 λ with 0° steering the beam also leaks sideways.
  6. Try the Alternating preset: neighbours in antiphase split the energy into two beams pointing sideways.
  7. Enable Auto-sweep to see an electronically scanned beam, as in radar and 5G base stations.
